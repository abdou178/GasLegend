# GasLegend — 24/7 Gas Safe Heating & Emergency Plumber
### Bolton & Greater Manchester (BL1–BL7, Bury, Wigan, Horwich, Westhoughton)

GasLegend is a high-converting, production-ready emergency heating and plumbing web application built with **Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide React, and `next-themes`**.

---

## Key Features

- **24/7 Live Emergency Standby Banner:** Real-time Bolton engineer dispatch availability and average 30–45 minute arrival time SLA.
- **Interactive Boiler Fault Triage:** Dynamic 30-second symptom selector with automated pre-filled WhatsApp SOS dispatch (`wa.me`).
- **Gas Safe Register Compliance:** Registration #941824 verification notice, £5,000,000 public liability insurance badge, and step-by-step Gas Make-Safe emergency guide.
- **OEM Brand Compatibility Matrix:** On-site error code diagnostics for Worcester Bosch, Vaillant, Ideal, Baxi, Viessmann, and Glow-worm.
- **Bolton Suburb & Postcode Coverage:** Interactive service locator covering BL1–BL7, Bury, Wigan, Horwich, Westhoughton, and Farnworth.
- **Transparent Pricing Guarantee:** Upfront rates with £79 fixed diagnostic fee 100% credited towards the repair cost.
- **Verified Customer Social Proof:** 4.9 ★★★★★ rating display with genuine UK homeowner reviews.
- **Sticky Mobile Dispatch Dock:** Floating 1-tap `📞 Call Gas Engineer` and `💬 WhatsApp SOS` actions for mobile screens.
- **Local SEO & Schema Markup:** Comprehensive JSON-LD structured data for `LocalBusiness`, `Plumber`, and `HVACBusiness` with Bolton geographical coordinates.
- **Dark & Light Mode:** Seamless theme switching with zero hydration mismatches.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
